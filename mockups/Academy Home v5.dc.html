USING THIS IN YOUR TEAM

Run the five steps as a group

Nothing here is arranged or sold. If several people want to go through the course together, run it the way anyone else does. This is what works best.

1Everyone signs up individually. Each person gets their own labs, baseline, and outcome sheet. 2Pick tracks by role, not by department. Each track states the role it was built for. 3Set one shared deploy date. Compare outcome sheets in a single review at the end.
